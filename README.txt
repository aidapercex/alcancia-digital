ALCANCÍA DIGITAL V4.1

Mejora de la V4 basada en pruebas de uso en celular. Conserva la clave local alcanciaV2 para mantener los datos existentes al actualizar.

Mejoras V4.1:
- Un solo botón “Editar movimientos”; Editar/Eliminar aparecen únicamente en modo edición.
- Registros múltiples agrupados visualmente, conservando cada movimiento individual editable.
- Historial separado por Hoy, Ayer y fecha.
- Filtros simples: Todos, Entradas y Retiros.
- Opción de deshacer una eliminación durante unos segundos, además de confirmación previa.
- Último movimiento visible de forma discreta en el inicio.
- Las notas solo ocupan espacio cuando existen.
- Mantiene validación para impedir existencias negativas.
- Mantiene todas las funciones V4: meta superada, porcentaje >100%, tablero de 100 casillas, sonidos, celebraciones, PIN, respaldo/restauración, inventario, PWA y funcionamiento offline.
- Caché actualizada a V4.1 para facilitar la actualización en GitHub Pages.

IMPORTANTE: el PIN es una barrera de privacidad local, no cifrado. La app no usa correo ni servidor para recuperar un PIN olvidado.
